# Pumpkin Patched
A Minecraft 26.1.2 mod designed to "patch" pumpkins for autumn by expanding their uses and relevance in the game. 

## Features
- **Big Pumpkins**: Big 3x3 block pumpkins that naturally generate in the world.
- **Baked Pumpkin Seeds**: A new food item that can be crafted from pumpkin seeds.
- **Eldritch Pumpkins**: A new type of pumpkin that can be found in the world.
  - **Carved Eldritch Pumpkins**: Can be carved like normal pumpkins, but with an eldritch texture.
  - **Eldritch Jack-o-Lanterns**: Can be crafted from carved eldritch pumpkins and a torch.
  - **Eldritch Pumpkin Patches**: Patches of eldritch pumpkins that can be found in the End biomes.
  - **Eldritch Pumpkin Seeds**: Can be used to grow eldritch pumpkins.
- **Ember Pumpkins**: A new type of pumpkin that can be found in the world.
  - **Carved Ember Pumpkins**: Can be carved like normal pumpkins, but with an ember texture.
  - **Ember Jack-o-Lanterns**: Can be crafted from carved ember pumpkins and a torch.
  - **Ember Pumpkin Patches**: Patches of ember pumpkins that can be found in the Nether biomes.
  - **Ember Pumpkin Seeds**: Can be used to grow ember pumpkins.
- **Pale Pumpkins**: A new type of pumpkin that can be found in the world.
  - **Carved Pale Pumpkins**: Can be carved like normal pumpkins, but with a pale texture.
  - **Pale Jack-o-Lanterns**: Can be crafted from carved pale pumpkins and a torch.
  - **Pale Pumpkin Patches**: Patches of pale pumpkins that can be found in the Pale Garden biome.
  - **Pale Pumpkin Seeds**: Can be used to grow pale pumpkins.
- **Pumpkin Bread**: A new food item that can be crafted from wheat and a pumpkin.
- **Sculk Pumpkins**: A new type of pumpkin that can be found in the world.
  - **Carved Sculk Pumpkins**: Can be carved like normal pumpkins, but with a sculk texture.
  - **Sculk Jack-o-Lanterns**: Can be crafted from carved sculk pumpkins and a torch.
  - **Sculk Pumpkin Patches**: Patches of sculk pumpkins that can be found in the Deep Dark biome.
  - **Sculk Pumpkin Seeds**: Can be used to grow sculk pumpkins.
- **Spooky Stew**: A new food item that can be crafted from a pumpkin, a mushroom, and a bowl. The effects of the stew depend on the type of pumpkin used.
  - **Eldritch Pumpkin**: 50% chance of Chorus Teleport (Instant) or Levitation (10 seconds)
  - **Ember Pumpkin**: 50% chance of Fire Resistance (15 seconds) or Fire (5 seconds)
  - **Pumpkin**: Regeneration (5 seconds)
  - **Pale Pumpkin**: 50% chance of Invisibility (10 seconds) or Slowness (10 seconds)
  - **Sculk Pumpkin**: 50% chance of Night Vision (15 seconds) or Blindness (15 seconds)
